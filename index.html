Learning Center

Choose the examination path you are preparing for. Core minimum-standards study is shared; rank-specific training builds on it.

How the learning paths work

Shared foundation: New York State Minimum Standards, numbers and timeframes, written material, reading comprehension, grammar, and exam strategy.

Rank-specific layer: Entry candidates focus on admissions, custody, safety, communication, and basic correctional operations. Promotional candidates add supervision, staff coordination, emergency response, program oversight, reporting, training, and command decision-making.

Course paths are study organization, not a claim that every title has an identical exam. Always follow the current examination announcement for the exact subject areas.

WRITTEN EXAM TRACK

Preparing Written Material

Paragraph sequencing and accurate information presentation.

Fast paragraph-sequencing method

  1. Find the broad opening sentence.
  2. Pair sentences using pronouns, repeated terms, and transitions.
  3. Follow chronology, cause/effect, or general-to-specific logic.
  4. Find the conclusion or result.
  5. Eliminate choices that start with a sentence depending on something not yet introduced.
